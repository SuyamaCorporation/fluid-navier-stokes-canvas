# Interactive Eulerian Fluid Canvas

## 概要
Jos Stamの安定流体アルゴリズムで非圧縮流体をcanvasリアルタイム描画（64×64グリッド）。マウスドラッグで速度場を入力し、密度/速度の可視化を切替できる。

## 機能
- Jos Stam安定流体アルゴリズム実装（64×64グリッド）
- マウスドラッグによる速度場の入力
- 密度/速度場の可視化切替
- 自動ソース（正弦波流入）のON/OFF
- クリアボタン
- タッチ操作対応

## 使い方
マウスをキャンバス上でドラッグすると流体が流れます。「Auto source」チェックで自動的に流体が追加されます。「Density」/「Velocity」で表示モードを切替えられます。
